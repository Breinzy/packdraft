# frontend/ — design snapshot

This folder is a **read-only visual reference** imported from `packdraft-frontend-06`.

The live product is `app/`.

Do not:

* Serve this Next app in production
* Use `lib/data.ts` mock prices as market truth
* Wire `lib/store.tsx` as a real collection ledger

The collector IA (Overview, Portfolio, Market, Watchlist, Sets) and visual tokens were ported into `app/` during the Phase 21–22 reorganization. Prefer changing `app/` going forward.
