# Packdraft — Release weekends

A campaign groups one portfolio tournament and several Market Events around a set drop.

## Isolation

The tournament book, Career book, and prediction events stay separate. No cash moves between them.

## Admin

`/admin` → Create release weekend. Picks priced assets from the chosen set (pads from the catalog if needed), then inserts `release_campaigns` + `release_campaign_items`.

Players browse `/releases` and `/releases/[id]`.
