# Packdraft — Creator tournaments

Creators host isolated virtual books with the same engine as admin tournaments.

## Flow

1. `/create` — claim a slug (`claim_creator_profile`) or host if already a creator / admin
2. `/creators/[slug]` — public page of that creator’s tournaments
3. Host form can mark a book public or private (invite link)

## Caps

Creators: budget ≤ $100,000, duration 1–30 days. Admins are not capped here. Entry is still free. No real money.

Sponsor labels are cosmetic. They do not promise prizes.
